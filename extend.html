How to make your html file better

1. Add image: there are 2 ways to add pictures into html file

1.1: Image from the internet

To add an image from the internet, we use " img scr="image-link" "

2.2: Image from you computer

To add an image that is from your computer, we use "img scr="image name" " If your image is inside a folder that's inside the main folder, we use folder-name/image name

2. Coding layout

First step:

We add doctype on the top of the file by typing DOCTYPE html

Second step:

Create a html tag, where all the coding will go (except for the doctype)

Third step:

Add a head tag inside the html tag. You can put the link to css file in here. Also add a body tag below the head tag, not inside. This is where all the visiable content will go

3. Add link

3.1: Link to CSS file

3.2: Link multiple page

If you have multiple html page, and you want to show a link to that page, we use White text next to the file name is the text that will be shown in your website, you can write whatever you want as long as the file name is correct
