WELCOME TO MY WEB DEVELOPMENT GUIDE

Introduction:

Have you ever wondered how websites are made? This website is designed to help beginners learn the fundamentals of web development using HTML and CSS.


HTML is used to structure the content of a webpage, while CSS controls its appearance including colors, fonts, spacing, and a lot more. By learning these 2 languages, you will be able to create your own beautiful websites from scratch.


I created this website to share what I have learned and make the process of building a website easier to understand. Instead of jumping straight into complicated code, we will go through the basics step by step, from writing your first HTML elements, styling your page and publishing it online.


No previous web development experience is required. All you need is a computer, Visual Studio Code, and a willingness to learn!
