HOW TO CREATE A WEBSITE

Step 1:

Go to "code.visualstudio.com", click Download on the top right corner adn download VScode



Step 2:

Once you have finished download and install VScode, create a new folder from file explorer. Then open Visual Studio Code and follow these steps:

File -> Open Folder -> Select the folder you created

Step 3:

Select create New File, named index.html and write HELLOOOOOO!



Step 4:

Check out your website! First save your file by pressing CTRL+S. Right click the file and choose "Reveal in File Explorer"

Now, double click the file to open your website.



Step 5:

We'll add a h1 element. Type h1 and press enter, you will see a h1 element in your file. Now put some text inside the h1 tags, let's see what will happen

Open the website again, don't forget to save your file before reloading the webpage.

We can add other elements for future styling them in css file. For example, p element stand for paragraph, which doesn't have any special effect to your text
