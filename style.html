HOW TO MAKE YOUR WEBSITE PRETTIER

1. Font and text

1.1: Font:

To add or change font for an element, we use font-family

1.2: Size:

To change text size, we use font-size

1.3 bold / light

To make text bold or lighter, we use font-weight

1.4: Style:

To italicise text, we use font-style

1.5: Underline:

To underline text, we use "text-decoration-line: overline/linethrough/underline
To change the style, we use "text-decoration-style: solid/dashed/dotted/wavy

1.6: Spacing between lines:

To adjust the spacing between lines, we use line-height

2. Colors For colors options, you can use CSS color names, or HEX code, or RGB values

2.1: Text color:

To change text color, we use "color"

2.2: Background color

To change backgound of color of an element, we use background-color

Opacity

To make an element partially transparent, we use "opacity"

3. Text alignment

To change the horizontal alignment of text inside an element, we use text-align: left/right/center/justify



4. Margin & padding

4.1: Margin

To add space outside an element, we use "padding" "margin:0 auto" is used with "fixed-width" element to center the element

4.2: To add space inside an element, we use "padding"



5. Border and corners

5.1: Border

To add a border, we use "border-style"
Heres are the border types

5.2: Border styling

"border-width" is used for changing the width of the border, and "border-color" is to change the color of the border

5.3

To round the corners, we use border-radius

6. Width and height Common units: px, %, vw, vh

6.1: Width

We use "width" to set an element width. You can also use "min-width" and "max-width" to set the limit

6.2: Height

Similar to width, you have "height, "min-height" and "max-heigh"

7. Background

7.1: Set a background

You can use a set color by the color code, or an image from your cumputer, by using "background-color: color code/name" or background-image: url("image name")

7.2: Background size

To set background size, we use "background-size"

7.2: Background positio

To set background postion, we use "background-position: left/ center/ right + top/ center/ bottom"

8. Display and layout

8.1: Types of display

To choose different types of display in an element, we use "display: block/ inline/ none/ flex"

8.2: Justify content

"justify-content: ...;" is used for ...

8.3: Align items

"align-tiem: ...; is used for ...

8.4: Sace between items

"gap" is used for creating gap between items in display

9. hover effect

9.1: hover effect

To add an effect that changes an element style whent he mouse is over it, we use "element name :hover"
