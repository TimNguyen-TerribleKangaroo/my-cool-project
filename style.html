HOW TO MAKE YOUR WEBSITE PRETTIER

1. Add image: there are multiple ways to add pictures into html file

First way: use immage link from the internet


Second way: use image from your computer, remember to put it in the same folder as your index file


2. Coding layout

First step:

We add doctype on the top of the file by typing DOCTYPE html

Second step:

Create a html tag, where all the coding will go (except for the doctype)

Third step:

Add a style tag inside of the html tag, this is where the style file link will go

Fourth step:

Add a body tag inside the html tag, where all the visiable content will go
3. Font, color, alignment

Font:

To add a font for an element, we use: Name of the element {font-family: name of the font}

Text color:

To change the color of the text, we use: Name of the element {color: name of the color} rgb stands for red, blue, green. You can you Rrgb color code for a specific color, or use the color picker by clicking the little square //immage
Or you can use color name instead of rgb code, e.g. blue, white, cyan

Background color:

You change the background color of a single element or the entire page by using body tag:
To change the background color of a single element, we use: Name of the element {background-color: name of the color}
Background color is similar to text color, you can use rgb code or name of the color

Align:

To align text, we use: Name of the element {text-align: left/center/right}

Margin

To add margin around an element, we use: Name of the element {margin: top/ right/ bottom/ left : ...px} px stand for pixels.

Border:

To add border around an element, we use: Name of the element {border: type width color}
Type of border: solid, dotted, dashed, double, .... You can search for border styles online; width of border can be defined in pixels (px)
You can also add round corner for border by using Name of the element {border-radius: ...px} //padding
