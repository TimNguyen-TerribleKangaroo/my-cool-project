HOW TO MAKE YOUR WEBSITE PRETTIER

1. Font, color, alignment

1.1: Font:

To add a font for an element, we use: Name of the element {font-family: name of the font}

1.2: Text color:

To change the color of the text, we use: Name of the element {color: name of the color} rgb stands for red, blue, green. You can you Rrgb color code for a specific color, or use the color picker by clicking the little square
CSS supports multiple color code system including color name, RGB, HEX,...

1.3: Background color:

You change the background color of a single element or the entire page by using body tag. To change the background color of a single element, we use: Name of the element {background-color: name of the color} Similar to text color, you can use different color code system as long as CSS supports it

1.4: Align:

To align text, we use: Name of the element {text-align: left/center/right}

1.5: Margin

To add margin around an element, we use: Name of the element {margin: top/ right/ bottom/ left : ...px} px stand for pixels.

1.6: Border:

To add border around an element, we use: Name of the element {border: type width color}
Type of border: solid, dotted, dashed, double, .... You can search for border styles online; width of border can be defined in pixels (px)
You can also add round corner for border by using Name of the element {border-radius: ...px}
