# How to Create Your First Website

A beginner-friendly website that teaches you how to create your own website using HTML and CSS.

## About the Project

This project contains three tutorials that guide beginners through the basics of website development:

- **Getting Started:** Learn the basics of HTML and create your first webpage.
- **Styling:** Learn how to use CSS to change colours, fonts, layouts, and more.
- **Publishing:** Learn how to publish your website online so other people can visit it.

## Technologies Used

- HTML
- CSS
- GitHub Pages

## Purpose

The purpose of this project is to help beginners understand the fundamentals of web development through simple explanations and practical examples.
